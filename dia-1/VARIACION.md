# Variacion: cupos limitados

El launchpad permitira un maximo de 10 inversiones exitosas.

- Cada inversion exitosa consumira un cupo.
- Una misma direccion podra consumir varios cupos.
- Las operaciones fallidas no consumiran cupos.
- Cuando no queden cupos, se rechazaran nuevas inversiones.
- Se permitira consultar cuantos cupos quedan.

Esta regla se implementara a partir del Dia 2.
La lista de direcciones autorizadas seguira siendo un requisito independiente.
